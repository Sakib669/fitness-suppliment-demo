# fitness-suppliment-demo

A high-performance, mobile-responsive fitness nutrition and sports supplement e-commerce experience built with **Next.js 16 (Turbopack)**, **React 19**, **TypeScript**, **Tailwind CSS**, and **localStorage** persistence.

## Features

- **Exact Design Fidelity**: Built to replicate high-converting sports nutrition storefront designs with clean, original non-infringing branding (*Zenith Performance Nutrition*).
- **Interactive Cart & Wishlist**: Real-time state syncing with browser `localStorage`, live item count badge, quantity management, and free-shipping progress indicators.
- **Dynamic Product Modals**:
  - **Quick View Modal**: Interactive flavor selection, serving information, and quick add-to-cart.
  - **Search Modal**: Instant client-side search filtering across names, categories, and tags.
  - **Wishlist Drawer**: Saved products management with instant cart transfer.
  - **Video Spotlight Modal**: High-definition athletic workout media modal.
  - **Article Reader**: Full-fidelity sports nutrition article reading modal.
- **Section Layouts**:
  - Top promotion bar with currency picker and support triggers.
  - Sticky glassmorphic navigation with mobile slide-out drawer.
  - 3D Hero with dynamic splash accents and carousel pagination.
  - Edge-to-edge touch-scrollable category pills.
  - Ice-blue "Premium Quality Products" catalog with rating stars.
  - High-impact animated marquee divider.
  - Science-backed formulation overview with laboratory trust badges.
  - Biomechanical features orbit detailing bioavailability and micronization.
  - Expert recommendations product carousel.
  - Full-width athletic gym video banner.
  - Optimum Gold Biomass spotlight with active dosage matrix.
  - Athlete and member testimonial reviews.
  - Sports nutrition insights journal.
  - Multi-column footer with organic ripped-paper edges.
- **Mobile Responsive**: Fully fluid across mobile (375px/390px), tablet (768px), and 4K desktop screens.

## Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org) (Turbopack)
- **UI Library**: React 19
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: GSAP (`@gsap/react`), Canvas Confetti
- **Icons**: Lucide React
- **Package Manager**: pnpm

## Getting Started

### 1. Install dependencies

```bash
pnpm install
```

### 2. Run development server

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### 3. Production build

```bash
pnpm build
pnpm start
```
